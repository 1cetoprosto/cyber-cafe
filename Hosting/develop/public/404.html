Потрібна Dev-збірка

Цей лінк з develop. App Store / TestFlight Beta його не відкриють автоматично — лише збірка TrackMyCafe Dev з Xcode.

Якщо Dev уже встановлений, але відкрився Safari:

  1. Поверніться в лист у «Пошта».
  2. Утримуйте синій лінк → Відкрити в TrackMyCafe.
  3. Не натискайте лінк звичайним тапом — iOS тоді знову відкриє браузер.

Після redirect у браузері код з листа вже «згорів» для цієї вкладки — потрібен саме long-press на оригінальний лінк у листі.

You need the Dev build

This link is for develop. The App Store / TestFlight Beta app will not open it automatically — only the TrackMyCafe Dev build from Xcode will.

If Dev is already installed but Safari opened:

  1. Go back to the email in Mail.
  2. Long-press the blue link → Open in TrackMyCafe.
  3. Don’t tap the link normally — iOS will open Safari again.

Once Safari has redirected here, this tab no longer carries the sign-in code — use long-press on the original email link.
